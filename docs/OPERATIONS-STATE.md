## 5. Gotchas that have cost hours

- `NEXT_PUBLIC_*` values are baked in at build time; a redeploy of an old build does not pick them up. (The pixel/GA4 IDs are therefore hard-coded as defaults in `track.ts`.)
- Clover Hosted Checkout allows one ecommerce token; payments are read back with a fallback path. A fraud-rule void (AVS) looks like "declined"; check Transactions → Voids.

- Meta "Publish" inside one ad's editor publishes only that ad; to publish selected ads, select them in the list and use the row's Publish.
- Google Ads new accounts are forced into a campaign wizard with no "expert mode" link; completing it (with billing) is the exit.
